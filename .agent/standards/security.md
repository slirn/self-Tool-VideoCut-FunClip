# 安全与隐私规范

## 目标

所有工程必须将安全、隐私和权限作为验收条件，而不是上线后的补充工作。具体技术实现服从项目上下文和适用法规。

## 必须遵守

- 认证、授权和租户边界必须在服务端校验；默认拒绝，遵循最小权限。
- 密钥、令牌、密码和生产配置不得提交到代码仓库、日志、错误响应或任务记录。
- 所有外部输入必须做类型、长度、范围、格式和权限校验；禁止拼接 SQL、命令、路径或 HTML。
- 敏感数据必须分类、最小化收集、加密传输，并按权限脱敏展示。
- 日志、导出、缓存、备份和测试数据必须执行同等敏感字段控制。
- 文件上传、下载、路径访问、反序列化、外部 URL 请求和 Webhook 必须限制来源、大小、协议和目标。
- 高风险权限、数据删除、迁移、外部兼容和基础设施操作必须明确批准并具备回滚方案。

## 验收

至少验证未授权访问、越权对象访问、输入攻击、敏感信息泄漏、审计记录和密钥扫描。发现漏洞时记录影响、临时缓解、修复和复测证据。
