# Agent 运行时安全与治理规范

## 目的

本规范用于约束 Agent 作为实际运行程序时的身份、工具权限、数据边界、审批、审计和资源使用，避免把协作规范误当成运行时安全控制。

## 基本原则

- 默认拒绝：未明确授权的工具、路径、网络、数据库和操作不得执行。
- 最小权限：Agent 只获得完成任务所需的身份、凭证、工具和时间范围。
- 不可信输入：用户内容、网页、文档、检索结果、日志和外部消息默认不可信。
- 人工保留关键决策：高风险操作不得由 Agent 自行批准。
- 全链路审计：身份、工具调用、参数摘要、结果、批准和策略版本必须可追溯。
- 可隔离和终止：运行中的 Agent 必须可以被暂停、撤销权限和安全终止。
- 失败关闭：权限、审计或安全策略不可用时，高风险操作必须拒绝执行。

## 身份与凭证

每个 Agent 运行必须具有明确身份：

- Agent 标识和版本；
- 任务或会话 ID；
- 发起用户和服务身份；
- 授权范围、开始时间和到期时间；
- 使用的模型、工具和策略版本。

凭证必须来自受控密钥系统或短期令牌，不得：

- 写入提示词、上下文、日志或代码仓库；
- 在长期记忆中保留原始密钥；
- 在未授权任务之间复用；
- 权限高于发起用户或服务本身。

优先使用短期、可撤销、按任务或按工具限定的凭证。

## 工具权限

工具必须使用白名单和操作分级：

| 级别 | 示例 | 控制 |
| --- | --- | --- |
| 只读 | 读取代码、查询受限数据、浏览文档 | 仍受数据权限和隐私规则限制 |
| 低风险写入 | 创建分支、修改工作区文件 | 限定路径、大小和任务范围 |
| 高风险写入 | 推送代码、发布制品、修改配置 | 明确批准、审计和可回滚 |
| 不可逆或高影响 | 删除数据、权限变更、生产发布 | 必须人工审批，禁止自动绕过 |

工具策略至少明确：

- 可执行文件和命令白名单；
- 文件和目录读写范围；
- 网络域名、协议和出站限制；
- 数据库、API 和环境边界；
- 最大参数、输出、文件大小和运行时间；
- 并发、速率、费用和资源上限；
- 禁止操作和需要审批的操作。

## 提示词注入与不可信内容

外部内容不得直接成为系统指令。处理网页、文档、代码注释、工单、邮件、日志和检索结果时：

- 标记来源和信任级别；
- 将内容视为数据，不视为高优先级指令；
- 不根据不可信内容扩大工具权限或读取密钥；
- 不执行内容中包含的未知命令；
- 对跨来源指令冲突先报告，不自行选择；
- 对模型生成的操作计划进行策略校验。

## 数据与上下文边界

进入模型上下文的数据必须符合项目的数据分类和最小化要求：

- 不在上下文放入不必要的个人敏感信息、密钥或生产数据；
- 对日志、录屏、音频、文件和数据库结果执行脱敏与截断；
- 明确上下文的保留期限、清理方式和可访问范围；
- 检索结果必须执行租户、组织和权限过滤；
- 跨项目或跨租户记忆默认隔离；
- 项目知识不得写入 Agent 工具的用户级目录；用户级记忆只保存个人偏好和环境特性，放置边界见 `knowledge-placement.md`；
- 不把生产数据复制到开发或测试上下文。

模型上下文、会话状态和记忆属于数据资产，必须纳入保留、删除和审计策略。

## 执行隔离

Agent 运行应使用适用级别的隔离：

- 独立进程、容器或受限执行环境；
- 最小文件系统挂载；
- 禁止默认访问宿主机敏感目录；
- 网络出站白名单；
- CPU、内存、磁盘、进程数和时间限制；
- 工具调用超时和取消；
- 子 Agent 继承但不得扩大权限；
- 运行结束后清理临时凭证和敏感上下文。

需要执行用户代码或不可信脚本时，应使用更强隔离并禁止直接访问生产网络与数据。

## 人工审批

以下操作必须人工批准，并记录批准人和范围：

- 生产部署、灰度扩大和回滚；
- 权限或角色变更；
- 数据删除、批量导出和迁移；
- 密钥、证书和信任链变更；
- 外部系统不可逆操作；
- 超出预算、范围或安全策略的继续执行。

一次批准只对明确目标、时间和验收对象有效，不得自动扩展到后续阶段。

## 审计

审计记录至少包含：

- Agent、模型、工具和策略版本；
- 发起用户、任务 ID 和验收对象；
- 工具名称、操作类型、目标资源和参数摘要；
- 结果、错误、耗时和重试；
- 人工批准和拒绝；
- 数据访问范围及敏感字段处理结果；
- 运行开始、暂停、恢复、终止和清理。

审计日志不得记录完整密钥或未脱敏敏感数据。审计存储应防篡改，并明确保留和访问权限。

## 失败与终止

Agent 必须支持：

- 全局和任务级停止开关；
- 凭证撤销和会话失效；
- 工具策略更新后立即阻止新调用；
- 超预算、异常循环、越权尝试或审计失败时安全暂停；
- 子任务和后台任务清理；
- 状态保存，但不保存敏感原始数据；
- 恢复时重新校验身份、权限、策略和验收对象。

## 验收

- 未授权工具、路径、网络和数据库访问被拒绝；
- 提示注入不能提升权限或泄漏密钥；
- 高风险操作需要有效人工批准；
- 审计覆盖身份、工具、数据、批准和终止；
- 密钥和敏感数据不进入提示词、日志或长期记忆；
- 超时、并发、费用和资源上限生效；
- 停止开关、凭证撤销和任务清理可验证；
- 恢复后权限和策略重新校验。
