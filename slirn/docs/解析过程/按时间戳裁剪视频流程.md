### 2.2 LLM 智能裁剪

| UI 控件 | 回调函数 | 文件:行 | 行为 |
|---|---|---|---|
| `llm_clip_button` | `AI_clip` | [launch.py:343-353](funclip/launch.py#L343-L353) | LLM 输出时间戳 → 裁剪 |
| `llm_clip_subti_button` | `AI_clip_subti` | [launch.py:354-364](funclip/launch.py#L354-L364) | LLM 输出时间戳 → 裁剪+字幕 |

二者都会先调用 `extract_timestamps(LLM_res)` 解析 LLM 输出中的 `[HH:MM:SS,mmm-HH:MM:SS,mmm]` 区间，然后**把 timestamp_list 当作已知时间戳直接传给 `video_clip`**：

```python
def AI_clip(LLM_res, dest_text, video_spk_input, start_ost, end_ost,
            video_state, audio_state, output_dir):
    timestamp_list = extract_timestamps(LLM_res)        # utils.trans_utils
    ...
    if video_state is not None:
        clip_video_file, message, clip_srt = audio_clipper.video_clip(
            dest_text, start_ost, end_ost, video_state,
            dest_spk=video_spk_input, output_dir=output_dir,
            timestamp_list=timestamp_list, add_sub=False)
        ...
```

> `extract_timestamps` 详见 [funclip/utils/trans_utils.py:113-124](funclip/utils/trans_utils.py#L113-L124)：用正则 `\[(\d{2}:\d{2}:\d{2},\d{2,3})\s*-\s*(\d{2}:\d{2}:\d{2},\d{2,3})\]` 把 `[00:00:01,000-00:00:04,400]` 这种时间区间抽出来，并通过 `convert_time_to_millis`（[trans_utils.py:108-111](funclip/utils/trans_utils.py#L108-L111)）把字符串转成毫秒。返回 `[[start_ms, end_ms], ...]`。

## 3. 核心方法 `VideoClipper.video_clip` 详解

**方法**：`VideoClipper.video_clip`  
**位置**：[funclip/videoclipper.py:261-371](funclip/videoclipper.py#L261-L371)

### 3.1 方法签名
```python
def video_clip(self,
               dest_text,        # 待裁剪文本（多段用 '#' 分隔；可带 [start_off,end_off] 前缀）
               start_ost,        # 开始偏移 ms

               font_size=32,     # 字幕字号

               dest_spk=None,    # 按说话人裁剪（多说话人用 '#' 分隔，spk0 / spk1 / ...）
               output_dir=None,  # 输出目录
               timestamp_list=None):  # LLM 模式直接传入时间戳（毫秒）
```

### 3.2 Step 1：从 state 还原依赖数据
```python

timestamp     = state['timestamp']        # 整段 token 级时间戳 [[s,e], ...]（毫秒）
sentences     = state['sentences']        # 句子级 list [{text, timestamp, spk?}, ...]
video         = state['video']            # moviepy VideoFileClip 对象
clip_video_file = state['clip_video_file']# 目标文件名（含 _clip 后缀）
video_filename  = state['video_filename'] # 原始视频路径
```

### 3.3 Step 2：解析出"所有时间区间" all_ts
代码用一个三分支结构：

```python
if timestamp_list is None:                       # ① 手动裁剪
    all_ts = []
    if dest_spk is None or dest_spk == '' or 'sd_sentences' not in state:
        # ② 文本匹配模式
        for _dest_text in dest_text.split('#'):
            if '[' in _dest_text:
                match = re.search(r'\[(\d+),\s*(\d+)\]', _dest_text)
                ...
                _dest_text = _dest_text[:_dest_text.find('[')]
            else:
                offset_b, offset_e = 0, 0
            _dest_text = pre_proc(_dest_text)
            ts = proc(recog_res_raw, timestamp, _dest_text.lower())
            for _ts in ts:
                all_ts.append([_ts[0]+offset_b*16, _ts[1]+offset_e*16])
    else:
        # ③ 说话人匹配模式
        for _dest_spk in dest_spk.split('#'):
            ts = proc_spk(_dest_spk, state['sd_sentences'])
            for _ts in ts:
                all_ts.append(_ts)
else:                                            # ④ LLM 模式
    all_ts = [[i[0]*16.0, i[1]*16.0] for i in timestamp_list]
```

#### 涉及到的辅助函数

| 函数 | 位置 | 作用 |
|---|---|---|
| `pre_proc(text)` | [utils/trans_utils.py:12-26](funclip/utils/trans_utils.py#L12-L26) | 去掉标点、汉字两侧加空格，便于按 token 匹配 |
| `proc(raw_text, timestamp, dest_text)` | [utils/trans_utils.py:28-41](funclip/utils/trans_utils.py#L28-L41) | 在 `recog_res_raw` 里 find 出 `dest_text` 出现的位置，再用 `timestamp` 表查 token 时间，**乘以 16**（1 ms = 16 个采样点 @ 16 kHz） |
| `proc_spk(dest_spk, sd_sentences)` | [utils/trans_utils.py:44-52](funclip/utils/trans_utils.py#L44-L52) | 遍历带说话人标签的句子，过滤 `str(d['spk']) == dest_spk[3:]` 的句子，返回 `[start*16, end*16]` |

> ⚠️ 单位一致性提醒：
> - `proc()` 和 `proc_spk()` 输出的 `all_ts` 单位都是 **采样点 (sample @ 16 kHz)**：所以 `timestamp[ti][0]` 原始是 ms，乘 16 后变 sample。
> - LLM 模式下 `timestamp_list` 是 **毫秒**，因此同样要乘 16 转成 sample。
> - 后续 `video.subclip(start, end)` 要求 **秒**，所以代码会再除以 16000（[videoclipper.py:318](funclip/videoclipper.py#L318)）。

### 3.4 Step 3：按区间循环裁剪 + 烧字幕 + 拼接
```python
srt_index = 0
time_acc_ost = 0.0          # 累计偏移（用于裁剪后片段顺序拼接时给字幕重新对齐）
ts = all_ts
clip_srt = ""

if len(ts):
    if self.lang == 'en' and isinstance(sentences, str):
        sentences = sentences.split()    # 英文：字符串拆 token

    # ── 第 1 段 ──
    start, end = ts[0][0] / 16000, ts[0][1] / 16000
    srt_clip, subs, srt_index = generate_srt_clip(
        sentences, start, end,
        begin_index=srt_index, time_acc_ost=time_acc_ost)
    start, end = start + start_ost/1000.0, end + end_ost/1000.0   # 用户偏移
    video_clip = video.subclip(start, end)                        # ★ moviepy 切片
    start_end_info = "from {} to {}".format(start, end)
    clip_srt += srt_clip
    if add_sub:
        generator = lambda txt: TextClip(
            txt, font='./font/STHeitiMedium.ttc',
            fontsize=font_size, color=font_color)
        subtitles = SubtitlesClip(subs, generator)                # ★ 生成字幕 Clip
        video_clip = CompositeVideoClip(
            [video_clip, subtitles.set_pos(('center','bottom'))]) # ★ 合成
    concate_clip = [video_clip]
    time_acc_ost += end - start

    # ── 第 2..N 段 ──
    for _ts in ts[1:]:
        start, end = _ts[0] / 16000, _ts[1] / 16000
        srt_clip, subs, srt_index = generate_srt_clip(
            sentences, start, end,
            begin_index=srt_index-1, time_acc_ost=time_acc_ost)
        if not len(subs):
            continue
        chi_subs = []
        sub_starts = subs[0][0][0]
        for sub in subs:
            # 把"绝对时间"重映射成"以本段起点为 0"的相对时间
            chi_subs.append(((sub[0][0]-sub_starts, sub[0][1]-sub_starts), sub[1]))
        start, end = start + start_ost/1000.0, end + end_ost/1000.0
        _video_clip = video.subclip(start, end)
        start_end_info += ", from {} to {}".format(str(start)[:5], str(end)[:5])
        clip_srt += srt_clip
        if add_sub:
            generator = lambda txt: TextClip(
                txt, font='./font/STHeitiMedium.ttc',
                fontsize=font_size, color=font_color)
            subtitles = SubtitlesClip(chi_subs, generator)
            _video_clip = CompositeVideoClip(
                [_video_clip, subtitles.set_pos(('center','bottom'))])
        concate_clip.append(copy.copy(_video_clip))
        time_acc_ost += end - start

    message = "{} periods found in the audio: ".format(len(ts)) + start_end_info

    # ── 多段拼接 ──
    if len(concate_clip) > 1:
        video_clip = concatenate_videoclips(concate_clip)

    # ── 落盘路径 ──
    if output_dir is not None:
        os.makedirs(output_dir, exist_ok=True)
        _, file_with_extension = os.path.split(clip_video_file)
        clip_video_file_name, _ = os.path.splitext(file_with_extension)
        clip_video_file = os.path.join(
            output_dir, "{}_no{}.mp4".format(clip_video_file_name, self.GLOBAL_COUNT))
        temp_audio_file = os.path.join(
            output_dir, "{}_tempaudio_no{}.mp4".format(clip_video_file_name, self.GLOBAL_COUNT))
    else:
        clip_video_file = clip_video_file[:-4] + '_no{}.mp4'.format(self.GLOBAL_COUNT)
        temp_audio_file = clip_video_file[:-4] + '_tempaudio_no{}.mp4'.format(self.GLOBAL_COUNT)
    self.GLOBAL_COUNT += 1

    # ── 最终输出 ──
    video_clip.write_videofile(
        clip_video_file, audio_codec="aac", temp_audiofile=temp_audio_file)
else:
    clip_video_file = video_filename
    message = "No period found in the audio, return raw speech. ..."
    srt_clip = ''

return clip_video_file, message, clip_srt
```

### 3.6 SRT 子串的生成
`generate_srt_clip(sentence_list, start, end, begin_index, time_acc_ost)`（[utils/subtitle_utils.py:69-132](funclip/utils/subtitle_utils.py#L69-L132)）：

```python
def generate_srt_clip(sentence_list, start, end, begin_index=0, time_acc_ost=0.0):
    start, end = int(start * 1000), int(end * 1000)   # 秒 → 毫秒
    srt_total, cc = '', 1 + begin_index
    subs = []
    for sent in sentence_list:
        if isinstance(sent['text'], str):
            sent['text'] = str2list(sent['text'])     # 字符串切成 token list
        if sent['timestamp'][-1][1] <= start:
            continue                                  # 完全在区间前
        if sent['timestamp'][0][0] >= end:
            break                                     # 完全在区间后
        # 中间四种 CASE：句子完全在区间内 / 部分重叠头部 / 部分重叠尾部
        ...
        t2s = Text2SRT(_text, _ts, offset=start)      # 重映射成"以 start 为 0"
        srt_total += "{}\n{}".format(cc, t2s.srt(time_acc_ost))
        subs.append((t2s.time(time_acc_ost), t2s.text()))
        cc += 1
    return srt_total, subs, cc
```

- 入参 `start, end` 是秒，内部转毫秒。
- 对每条 `sent`，根据 token 时间戳与区间的关系裁出重叠部分，构造 `Text2SRT`。
- `Text2SRT`（[utils/subtitle_utils.py:29-54](funclip/utils/subtitle_utils.py#L29-L54)）通过 `time_convert(ms)` 把 ms 转 `HH:MM:SS,mmm` 格式。
- 同步返回 `subs = [((t_start_sec, t_end_sec), text), ...]`，供 `SubtitlesClip` 烧到画面上。
- `time_acc_ost` 用于多段拼接时让每段的 SRT 时间戳按"拼接后总视频"重新累计（不再从 0 开始）。

## 5. 数据形态参考

### 5.1 时间戳单位换算
| 阶段 | 单位 | 说明 |
|---|---|---|
| `proc()` / `proc_spk()` 返回 | **sample @ 16 kHz**（毫秒 × 16） | 整段 token 时间戳天然是毫秒，乘 16 转 sample |
| `extract_timestamps()` 返回 | **毫秒** | LLM 输出文本里直接给 `[HH:MM:SS,mmm]`，字符串解析后是 ms |
| `video_clip` 内部 `ts = [[ms*16, ms*16], ...]` | **sample** | 把 LLM 模式输入也对齐成 sample |
| `start, end = ts[i][0] / 16000, ts[i][1] / 16000` | **秒** | 转成 moviepy 用的秒 |
| `start + start_ost/1000.0` | **秒 + ms→秒** | 用户给的 `start_ost` 单位是 ms |
| `generate_srt_clip(..., start, end)` 内部 | 入参秒 → 转毫秒 | 与 SRT 标准对齐 |
| SRT 输出 | **`HH:MM:SS,mmm`** | 标准 SRT 文本 |

### 5.2 手动模式 dest_text 语法
```
<待裁剪文字>             # 单段，例如 "我们把它跟乡村振兴去结合起来"
<待裁剪文字>[b,e]        # 单段 + 时间偏移（毫秒） 例如 "那一段[100,200]"
段1#段2#段3              # 多段并行裁剪（用 # 分隔）
```

解析逻辑（[videoclipper.py:283-295](funclip/videoclipper.py#L283-L295)）：
- 如果含 `[`，正则 `re.search(r'\[(\d+),\s*(\d+)\]', _dest_text)` 抽两个整数当毫秒偏移；
- 截掉 `[...]` 后面的部分；
- `offset_b * 16` / `offset_e * 16` 加到区间起点 / 终点（单位统一成 sample）。

### 5.3 LLM 模式 LLM 输出示例
```
1. [00:00:01,000-00:00:04,400] 讲点那个一些自己的经验吧
2. [00:00:07,120-00:00:12,940] 啊，在这样一个我们叫寻美在这样的一个项目当中...
3. [00:00:13,240-00:00:25,620] 问我们自身员工的设设计能力...
```
- `extract_timestamps` 只关心 `[...]` 区间，文本内容会被忽略。
- 文本内容对裁剪没影响，纯粹给人类阅读。
- 时间格式严格要求 `\d{2}:\d{2}:\d{2},\d{2,3}`，毫秒部分 2-3 位数字。

### 5.4 dest_spk 语法
```
spk0           # 单个说话人（必须是 `spk` 前缀 + 数字）
spk0#spk2      # 多个说话人
```
- `proc_spk` 会取 `dest_spk[3:]` 作为数字部分，再过滤 `str(d['spk']) == spkid` 且 `d_end - d_start > 999` ms 的句子。

### 5.5 state 必备字段
```python
state = {
    "video_filename":  "...mp4",
    "clip_video_file": "..._clip.mp4",
    "video":           <VideoFileClip>,
    "recog_res_raw":   "...token 串...",
    "timestamp":       [[s,e], ...],   # 毫秒
    "sentences":       [{text, timestamp, spk?}, ...],
    "sd_sentences":    [...]            # 仅 sd 模式存在
}
```

### 5.6 返回值
| 名称 | 类型 | 含义 |
|---|---|---|
| `clip_video_file` | `str` | 落盘后的 mp4 路径（带 `_no{N}.mp4` 后缀以防同名覆盖） |
| `message` | `str` | 裁剪日志，如 `"3 periods found in the audio: from 1.0 to 4.4, from 7.1 to 12.9, ..."` |
| `clip_srt` | `str` | 被裁剪段对应的 SRT 字符串（每段独立 1..N 编号） |

## 6. 4 条入口的差异对照

| 入口 | 触发回调 | 时间戳来源 | 是否烧字幕 | dest_text 用法 |
|---|---|---|---|---|
| `clip_button` | `mix_clip` | 手动（`proc` / `proc_spk`） | 否 | 作为查询关键字 |
| `clip_subti_button` | `video_clip_addsub` | 手动 | 是 | 作为查询关键字 |
| `llm_clip_button` | `AI_clip` | LLM（`extract_timestamps`） | 否 | 传参保留但不被使用 |
| `llm_clip_subti_button` | `AI_clip_subti` | LLM | 是 | 传参保留但不被使用 |

> 在 LLM 模式下 `dest_text` / `dest_spk` 仍被传入 `video_clip` 但因为 `timestamp_list is not None`，会走 else 分支被忽略。

## 7. 一句话串讲

> 用户点击裁剪按钮 → 入口函数（`mix_clip` / `video_clip_addsub` / `AI_clip` / `AI_clip_subti`）规整参数 → `VideoClipper.video_clip` 从 state 取出 `recog_res_raw / timestamp / sentences / video` → 根据是否提供 `timestamp_list` 选择「手动 `proc`/`proc_spk`」或「LLM 直接传入」得到一组时间区间（sample 单位） → 遍历每个区间，先用 `generate_srt_clip` 拿区间内的 SRT 子串和 `(start,end,text)` 元组，再用 `video.subclip` 切出对应视频段，可选用 `SubtitlesClip + CompositeVideoClip` 烧字幕到画面底部，最后用 `concatenate_videoclips` 把多段首尾拼接成一个 mp4 并以 `write_videofile(audio_codec="aac")` 落盘，UI 同时拿到「裁剪后视频路径 + 日志信息 + 该段 SRT」。
