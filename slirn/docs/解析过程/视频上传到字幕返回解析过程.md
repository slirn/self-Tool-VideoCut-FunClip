# FunClip 视频上传 → 字幕内容/时间信息返回 解析过程

> 适用代码版本：FunClip-main（funclip/launch.py + funclip/videoclipper.py + funclip/utils/*）
> 关注范围：从用户在 Gradio 界面中上传视频文件开始，到前端拿到「识别文本 + SRT 字幕 + 状态对象」结束的整条调用链。

### 阶段 ②：分发到视频识别入口
**函数**：`mix_recog`  
**位置**：[funclip/launch.py:94-112](funclip/launch.py#L94-L112)

关键步骤：
1. 规整 `output_dir`：空字符串 → `None`，否则取 `os.path.abspath(output_dir)`。
2. 优先处理视频输入：调用
   ```python

       video_input, 'No', hotwords, output_dir=output_dir)
   ```
   这里的 `video_input` 在 Gradio 端是视频文件的 **磁盘路径**（Gradio 会先把上传的视频保存到临时目录，再把路径传入）。
3. 把识别文本和 SRT 写到 `output_dir`：
   ```python

   srt_file  = save_text_to_file(res_srt, 'srt', output_dir)
   ```
4. 返回 6 个值到 UI：

- 用 `datetime.now().strftime("%Y%m%d_%H%M%S")` 生成时间戳文件名 `result_{时间}.{扩展}`。

### 阶段 ④：VideoClipper.video_recog —— 拆音轨
**方法**：`VideoClipper.video_recog`  
**位置**：[funclip/videoclipper.py:229-259](funclip/videoclipper.py#L229-L259)

调用链：

| 步骤 | 调用 | 来源 / 说明 |
|---|---|---|
| 1 | `mpy.VideoFileClip(video_filename)` | [moviepy](https://zulko.github.io/moviepy/) 打开视频对象（懒加载，仅读取元数据） |
| 2 | `os.makedirs(output_dir, exist_ok=True)` | 若 `output_dir` 非空则创建 |
| 3 | 拼接临时音频路径 `base_name + '.wav'` | 文件名与视频同名，仅换后缀 |
| 4 | `video.audio.write_audiofile(audio_file)` | **关键步骤**：用 moviepy 把视频里的音轨解码并写成一个 WAV 文件 |
| 5 | `wav = librosa.load(audio_file, sr=16000)[0]` | 用 [librosa](https://librosa.org/) 读取 WAV，统一重采样到 **16 kHz 单声道**，返回 `numpy.ndarray` |
| 6 | `os.remove(audio_file)` | 删掉临时 WAV，节省磁盘 |
| 7 | 构造 `state` 字典：`video_filename / clip_video_file / video` | state 用于后续裁剪 |
| 8 | `return self.recog((16000, wav), sd_switch, state, hotwords, output_dir)` | 把 16 kHz 的 numpy 数组喂给 `recog` |

> 注意：这里没有调用 ffmpeg 子进程，而是走 moviepy 的解码路径（moviepy 内部仍可能 fork ffmpeg）。最终落盘的「临时 WAV」是真正承载音频数据的物理文件，但用完即删。

### 阶段 ⑤：VideoClipper.recog —— 调 FunASR + 标准化输出
**方法**：`VideoClipper.recog`  
**位置**：[funclip/videoclipper.py:118-162](funclip/videoclipper.py#L118-L162)

```python
def recog(self, audio_input, sd_switch='no', state=None, hotwords="", output_dir=None):
    sr, data = audio_input
    data = convert_pcm_to_float(data)             # utils.trans_utils
    if sr != 16000:
        data = librosa.resample(data, orig_sr=sr, target_sr=16000)
    if len(data.shape) == 2:
        data = data[:, 0]                         # 多通道只取第一通道
    state['audio_input'] = (sr, data)

    if sd_switch == 'Yes':
        rec_result = self.funasr_model.generate(
            data, return_spk_res=True, return_raw_text=True,
            is_final=True, output_dir=output_dir, hotword=hotwords,
            pred_timestamp=self.lang=='en',
            en_post_proc=self.lang=='en', cache={})
    else:
        rec_result = self.funasr_model.generate(
            data, return_spk_res=False, sentence_timestamp=True,
            return_raw_text=True, is_final=True,
            hotword=hotwords, output_dir=output_dir,
            pred_timestamp=self.lang=='en',
            en_post_proc=self.lang=='en', cache={})

    res_text, raw_text, timestamp, sentence_info = _normalize_recognition_result(rec_result[0])
    res_srt = generate_srt(sentence_info)
    if sd_switch == 'Yes':
        state['sd_sentences'] = sentence_info
    state['recog_res_raw'] = raw_text
    state['timestamp']     = timestamp
    state['sentences']     = sentence_info
    return res_text, res_srt, state
```

子步骤逐项：

#### 5.1 音频预处理
- `convert_pcm_to_float(data)`（[funclip/utils/trans_utils.py:88-106](funclip/utils/trans_utils.py#L88-L106)）
  - 把 `int8 / int16 / int32 / float32` 统一转成 `float64`，必要时除以 `2^(bit-1)` 做归一化。
- `librosa.resample(...)`：在 `sr != 16000` 时把采样率重新采样到 16 kHz（一般 `video_recog` 阶段已经重采样过了，此处再次防御性检查）。
- `data[:, 0]`：多通道取第一通道（防止 2D 数组进 FunASR 报错）。

#### 5.2 FunASR 推理调用
- 入口：`funasr.AutoModel.generate(...)`，调用哪个模型取决于 `launch.py` 启动参数：
  - `--model fun-asr-nano` → `FunAudioLLM/Fun-ASR-Nano-2512`（[launch.py:32-40](funclip/launch.py#L32-L40)）
  - `--model sensevoice` → `iic/SenseVoiceSmall`（[launch.py:41-46](funclip/launch.py#L41-L46)）
  - 默认（paraformer） → `iic/speech_seaco_paraformer_large_asr_nat-zh-cn-16k-common-vocab8404-pytorch` + `fsmn-vad` + 标点 + 说话人模型（[launch.py:47-52](funclip/launch.py#L47-L52)）
- 关键参数含义：
  - `return_spk_res`：是否返回说话人区分结果（CAM++）。
  - `sentence_timestamp`：是否带句子级时间戳。
  - `return_raw_text`：返回无标点的原始文本。
  - `is_final`：流式场景下取最终结果。
  - `hotword`：热词字符串（空格分隔）。
  - `pred_timestamp` / `en_post_proc`：英文模式下的时间戳预测与后处理开关。

#### 5.3 结果标准化
`_normalize_recognition_result(rec_result[0])`（[videoclipper.py:92-109](funclip/videoclipper.py#L92-L109)）：

```python
text      = _clean_recognition_text(result.get("text") or result.get("text_tn") or result.get("raw_text") or "")
raw_text  = _clean_recognition_text(result.get("raw_text") or result.get("text_tn") or text)
timestamp = result.get("timestamp") or result.get("timestamps") or []

sentence_info = []
for sent in result.get("sentence_info") or []:
    if _is_valid_timestamp(sent.get("timestamp")):
        sentence_info.extend(_split_long_sentence(sent))

if not sentence_info and text and _is_valid_timestamp(timestamp):
    sentence_info = _split_long_sentence({"text": text, "timestamp": timestamp})

return text, raw_text, timestamp, sentence_info
```

辅助函数：

- `_is_valid_timestamp(ts)`（[videoclipper.py:30-36](funclip/videoclipper.py#L30-L36)）
  时间戳必须是「非空 list 且首末元素都不为 None」。
- `_clean_recognition_text(text)`（[videoclipper.py:39-44](funclip/videoclipper.py#L39-L44)）
  - 用正则 `SENSEVOICE_TAG_RE = re.compile(r"<\|[^|>]+\|>")` 去掉 SenseVoice 模型自带的标签（`<|zh|>`、`<|HAPPY|>` 等）。
  - 合并多余空白。
  - 去掉首尾的「" "」中文引号。
- `_split_long_sentence(sent)`（[videoclipper.py:47-89](funclip/videoclipper.py#L47-L89)）
  - 调用 `str2list(cleaned_text)`（[subtitle_utils.py:24-27](funclip/utils/subtitle_utils.py#L24-L27)）把字符串按「中文单字 / 英文单词」切分。
  - 如果一条句子的时长 ≥ `MAX_SUBTITLE_DURATION_MS=8000` ms 或字数 ≥ `MAX_SUBTITLE_TOKENS=30`，则把它切成多条短字幕，避免 SRT 单条过长。
  - 切分时尽量保持 token 与 timestamp 一一对应。

#### 5.4 生成 SRT 字符串
`generate_srt(sentence_info)`（[funclip/utils/subtitle_utils.py:57-67](funclip/utils/subtitle_utils.py#L57-L67)）：

```python
def generate_srt(sentence_list):
    srt_total = ''
    for i, sent in enumerate(sentence_list):
        if not sent.get('timestamp'):
            continue
        t2s = Text2SRT(sent['text'], sent['timestamp'])
        if 'spk' in sent:
            srt_total += "{}  spk{}\n{}".format(i + 1, sent['spk'], t2s.srt())
        else:
            srt_total += "{}\n{}".format(i + 1, t2s.srt())
    return srt_total
```

`Text2SRT`（[subtitle_utils.py:29-54](funclip/utils/subtitle_utils.py#L29-L54)）：

```python
class Text2SRT():
    def __init__(self, text, timestamp, offset=0):
        self.token_list = text
        self.timestamp = timestamp
        start, end = timestamp[0][0] - offset, timestamp[-1][1] - offset
        self.start_sec, self.end_sec = start, end
        self.start_time = time_convert(start)
        self.end_time   = time_convert(end)

    def text(self):
        # 中文逐字拼接，英文之间用空格拼接；去掉末尾的「、。，」标点

    def srt(self, acc_ost=0.0):
        return "{} --> {}\n{}\n".format(
            time_convert(self.start_sec + acc_ost*1000),
            time_convert(self.end_sec   + acc_ost*1000),
            self.text())

    def time(self, acc_ost=0.0):
        return (self.start_sec/1000 + acc_ost, self.end_sec/1000 + acc_ost)
```

- `time_convert(ms)`（[subtitle_utils.py:7-22](funclip/utils/subtitle_utils.py#L7-L22)）
  把毫秒转成 SRT 标准时间格式 `HH:MM:SS,mmm`（左侧自动补 0）。
- 整段 SRT 的最终样例：
  ```
  1
  00:00:00,000 --> 00:00:01,000
  最后一节课了

  2
  00:00:01,000 --> 00:00:04,400
  讲点那个一些自己的经验吧
  ```

#### 5.5 写入 state 并返回
```python
state['recog_res_raw'] = raw_text      # 带空格的整段「原始 token 串」，供后续 proc() 文本匹配
state['timestamp']     = timestamp     # 整段级 token 时间戳（毫秒）
state['sentences']     = sentence_info # 句子级 [{text, timestamp, spk?}, ...]
state['sd_sentences']  = sentence_info # 仅区分说话人模式下，额外保存一份
```

最终 `recog()` 返回 `(res_text, res_srt, state)`。

## 4. 数据形态参考

### 4.1 `funasr_model.generate(...)` 返回值
FunASR 的 AutoModel 返回一个 list（即使只处理一段），每个元素是 dict：

```python
rec_result[0] = {
    "text": "最 后 一 节 课 了",                       # 带空格、按 token 拆的「显示文本」
    "text_tn": "最后一节课了",                         # 拼接后的真实文本
    "raw_text": "最 后 一 节 课 了 讲 点 那 个 一 些 ...",  # 整段无标点 token 流（用于后续文本匹配）
    "timestamp": [[0, 1000], [1000, 4400], ...],      # token 级别时间戳，毫秒
    "sentence_info": [
        {
            "text": "最后一节课了",
            "timestamp": [[0, 1000]],                 # 句子级 token 时间戳
            "spk": 0                                  # 仅 sd 模式存在
        },
        ...
    ]
}
```

### 4.2 视频输入 → 状态对象 state
经过 `video_recog` → `recog` 后，state 至少包含：

```python
state = {
    "video_filename":  "...mp4",      # 视频原始路径
    "clip_video_file": "..._clip.mp4",# 后续裁剪产物名
    "video":           <VideoFileClip>,  # moviepy 视频对象
    "audio_input":     (16000, ndarray),  # 16 kHz float64 单声道音频
    "recog_res_raw":   "...",         # 整段 token 串（空格分隔）
    "timestamp":       [[s, e], ...], # 整段 token 时间戳（毫秒）
    "sentences":       [...],         # 句子级 list
    "sd_sentences":    [...]          # 仅 sd 模式存在
}
```

### 4.3 返回到 UI 的 6 个值
| 顺序 | 名称 | 类型 | 含义 |
|---|---|---|---|

## 6. 一句话串讲

> 用户上传视频 → `mix_recog` 分发 → `video_recog` 用 MoviePy 抽音轨、librosa 转 16 kHz 单声道 ndarray → `recog` 预处理后调用 `funasr.AutoModel.generate` 做 ASR → `_normalize_recognition_result` 清洗 SenseVoice 标签、按 token/时长拆长句 → `generate_srt` 借助 `Text2SRT + time_convert` 把每条句子拼成 SRT 串 → `save_text_to_file` 把 txt/srt 写到 `output_dir` → 返回 `(res_text, res_srt, state, None, text_file, srt_file)` 到 Gradio，UI 同时拿到「字幕内容 + 时间信息 + 可下载文件 + 可复用的 state」。
