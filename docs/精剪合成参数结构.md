# 精剪合成 · 保存的设置参数结构

## 1. 存储位置

这组参数保存在两处，字段结构完全相同：

| 存储 | 文件 | 形态 |
|---|---|---|
| 任务设置 | `slirn-standalone/tasks/<任务ID>/fine_compose.json` | 六组参数在文件顶层 |
| 全局模板 | `slirn-standalone/tasks/_global_fine_profiles.json` | 同一组参数包在每条模板的 `params` 下（包裹结构见 §4） |

## 2. 完整结构（六组参数 + 默认值）

```json
{
  "layout": {
    "video":    { "x": 0,  "y": 0,   "scale": 0.7, "crop_x": 0, "crop_y": 0,
                  "crop_w": 1920, "crop_h": 1080, "enabled": true, "crop_aspect_lock": true },
    "subtitle": { "x": 672, "y": 972, "scale": 1.0, "enabled": true },
    "cover":    { "enabled": false, "duration": 2.0 },
    "bg":       { "x": 0,  "y": 0,   "scale": 1.0, "enabled": false }
  },

  "font": {
    "size": 36,               "color": "#FFFFFF",
    "stroke_width": 2,        "stroke_color": "#000000",
    "bg_enabled": false,      "bg_color": "#000000",
    "bg_opacity": 0.6,        "bg_radius": 4,
    "bold": true,             "align": "center",
    "offset": 0,              "family": "STHeitiMedium"
  },

  "output": { "resolution": "1080p", "codec": "h264", "audio_codec": "aac" },

  "audio": { "enabled": false, "volume_db": -8.0, "fade_in": 0.0, "fade_out": 0.0 },

  "preview": { "start_h": 0, "start_m": 0, "start_s": 0, "duration": 10 },

  "detected_region": {
    "x": 0, "y": 0, "width": 0, "height": 0,
    "center_x": 0, "center_y": 0,
    "corners": [[x, y], [x, y], [x, y], [x, y]],
    "pixel_count": 0,
    "image_native_w": 0, "image_native_h": 0,
    "algorithm": "auto", "threshold": null,
    "detected_color": [255, 255, 255],
    "color_tolerance": 30,
    "detected_at": "2026-09-30T14:00:00"
  }
}
```

未做过背景人像区检测时 `detected_region` 为 `null`。

## 3. 字段说明

### 3.1 `layout` — 画布内各元素布局

坐标基准：固定设计空间 **1920×1080 像素**（与导出分辨率无关，渲染时等比映射）。

**`layout.video`**（视频窗格）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `x` / `y` | int | 0 / 0 | 视频窗格在画布内的位置（像素） |
| `scale` | float | 0.7 | 缩放比例（0.7 = 占宽 70%，右侧留给背景图人像区） |
| `crop_x` / `crop_y` / `crop_w` / `crop_h` | int | 0 / 0 / 1920 / 1080 | 从**源视频**截取的矩形（设计空间像素，渲染时按源视频实际尺寸等比换算）；全幅 = 不裁剪 |
| `enabled` | bool | true | 视频是否参与合成 |
| `crop_aspect_lock` | bool | true | 裁剪框是否锁定 16:9 比例（false 允许任意宽高比，如 1:1） |

**`layout.subtitle`**（字幕）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `x` / `y` | int | 672 / 972 | 字幕锚点位置（像素）；`align=center / center_offset` 时 x 不生效，由对齐方式决定 |
| `scale` | float | 1.0 | 字幕整体缩放 |
| `enabled` | bool | true | 字幕是否渲染 |

**`layout.cover`**（片头封面）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | false | 是否加片头全屏海报 |
| `duration` | float | 2.0 | 封面展示秒数 |

**`layout.bg`**（背景图）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `x` / `y` | int | 0 / 0 | 背景图位置（像素） |
| `scale` | float | 1.0 | 背景图缩放 |
| `enabled` | bool | false | 背景图是否参与合成 |

### 3.2 `font` — 字幕文字样式

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `size` | float | 36 | 字号 |
| `color` | string | `#FFFFFF` | 文字颜色（`#RRGGBB`） |
| `stroke_width` | float | 2 | 描边宽度（0 = 无描边） |
| `stroke_color` | string | `#000000` | 描边颜色 |
| `bg_enabled` | bool | false | 是否加字幕底衬色块 |
| `bg_color` | string | `#000000` | 底衬颜色 |
| `bg_opacity` | float | 0.6 | 底衬不透明度（0–1） |
| `bg_radius` | float | 4 | 底衬圆角（像素） |
| `bold` | bool | true | 粗体 |
| `align` | string | `center` | 对齐：`left` / `center` / `right` / `center_offset`（居中+偏移） |
| `offset` | int | 0 | `align=center_offset` 时相对屏幕中心的水平偏移像素（负 = 左偏，正 = 右偏；其他对齐模式忽略） |
| `family` | string | `STHeitiMedium` | 字体名 |

### 3.3 `output` — 导出编码

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `resolution` | string | `1080p` | 导出分辨率：`720p` / `1080p` / `source`（跟随源） |
| `codec` | string | `h264` | 视频编码 |
| `audio_codec` | string | `aac` | 音频编码 |

### 3.4 `audio` — 背景音乐

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | false | BGM 是否混入 |
| `volume_db` | float | -8.0 | BGM 音量，dB 衰减（0 = 原曲，-40 ≈ 静音；范围 [-40, 0]） |
| `fade_in` | float | 0.0 | 淡入秒数 |
| `fade_out` | float | 0.0 | 淡出秒数 |

### 3.5 `preview` — 预览区间参数

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `start_h` / `start_m` / `start_s` | int | 0 / 0 / 0 | 预览起点时分秒 |
| `duration` | int | 10 | 预览时长（秒） |

### 3.6 `detected_region` — 背景图人像区检测结果

| 字段 | 类型 | 说明 |
|---|---|---|
| `x` / `y` / `width` / `height` | int | 检测矩形（背景图原生像素） |
| `center_x` / `center_y` | int | 矩形中心 |
| `corners` | array | 四角坐标 `[x, y]` × 4 |
| `pixel_count` | int | 命中像素数 |
| `image_native_w` / `image_native_h` | int | 背景图原生尺寸 |
| `algorithm` | string | 检测算法（如 `pixel` / `auto`） |
| `threshold` | int\|null | 算法阈值 |
| `detected_color` | [r,g,b] | 命中颜色（颜色算法才有） |
| `color_tolerance` | int | 颜色容差（颜色算法才有） |
| `detected_at` | string | 检测时间（ISO） |

## 4. 存为全局模板时的包裹结构

`tasks/_global_fine_profiles.json`：

```json
{
  "_schema": 1,
  "profiles": [
    {
      "id": "p_20260930_140139_6d9bde",
      "name": "教学片头",
      "saved_at": "2026-09-30T14:01:39",
      "task_id_origin": "20260924-001",
      "params": {
        "layout":          { "…同 §3.1…" : "" },
        "font":            { "…同 §3.2…" : "" },
        "output":          { "…同 §3.3…" : "" },
        "audio":           { "…同 §3.4…" : "" },
        "detected_region": { "…同 §3.6…" : "" },
        "preview":         { "…同 §3.5…" : "" }
      }
    }
  ],
  "updated_at": "2026-09-30T14:01:55"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `p_<时间戳>_<随机hex>`，全局唯一 |
| `name` | string | 模板名（重名自动加 `(2)` 后缀） |
| `saved_at` | string | 保存时间，列表按此倒序 |
| `task_id_origin` | string | 溯源：从哪个任务存出 |
| `params` | object | §2 的六组参数，结构与任务级完全相同 |
