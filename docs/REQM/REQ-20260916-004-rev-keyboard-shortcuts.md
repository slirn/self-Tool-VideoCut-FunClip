## 1. 需求（用户原话转述）

> 在字幕修订阶段，我想给右边区域添加快捷键。快捷键包括，选择上一条字幕、选择下一条
> 字幕，播放、暂停、保留、删除、切分这些快捷键，如果按了切分键的话，自动打开折叠的
> 下面区域，并把光标移到手动处理说明区域中。这样方便对字幕信息进行人工处理和剪辑。
> 你可以精心设计一下这几个快捷键如何设计更方便用户操作。

## 2. 设计

### 2.1 键位表（双手分工，挑选式节奏：听 → 判 → 标记 → 下一条）

| 键 | 动作 | 细节 |
|---|---|---|
| `↑` / `↓` | 上一条 / 下一条 | 首次 `↓` 选第 1 行、`↑` 选最后一行；选中行滚动到可见 + 跳到该行起点；**播放中续播，暂停时只选不强制播**（按空格续听） |
| `空格` | 播放 / 暂停 | 切换式（一个键覆盖用户列的「播放、暂停」两个诉求）；从未播放过 → 从选中行（或第一行）起点开播 |
| `R` | 重播本行 | 无论暂停与否，从当前选中行起点重新播放 |
| `K` | 保留 | 设决策下拉 = 保留，**自动跳下一条**（标记即过） |
| `D` | 删除 | 设决策下拉 = 删除，**自动跳下一条** |
| `S` | 切分 | 设决策下拉 = 切分 → **展开该行详情块 + 光标移入「手动处理说明」输入框**（不跳行；写完按 `Esc` 返回列表继续） |
| `Esc` | 退出输入框 | 从手动说明输入框退回列表快捷键状态 |

设计考量：
- **单键无修饰**：组合键易与浏览器/系统冲突，且按起来慢；修饰键组合一律放行不拦截。
- **K/D/S 助记**（Keep/Delete/Split），提示条常驻列表上方，不依赖记忆。
- **K/D 自动跳行 + R 重播**是补充设计：389 条逐条过，标准节奏变成
  ↓（听）→ 判断 → K/D 直接下一条；没听清按 R 重听；拿不准按 S 写说明。
- 鼠标点击行 = 定位播放 + 同步设为「当前行」，与键盘共享选中态。

### 2.2 防误触与作用域（三层门控）

- **输入保护**：焦点在文本框/下拉/富文本内时按键不劫持（打字照常、下拉 ↑↓ 原生）；
  空格的 `preventDefault` 同时避免「焦点残留在按钮上时空格误触发按钮」（如误再保存）。
- **长按防误触**：K/D/S/R/空格忽略按键重复（按住不放不会连环标记几十行）；↑↓ 允许重复（快速滚动）。
- **可见性门控**：修订列表不可见（工作台切到其他阶段面板 / 详情页）→ 快捷键整体不生效。
- **修饰键放行**：Ctrl/Cmd/Alt 组合不拦截。

### 2.3 视觉

- 键盘选中行 `.kbsel`：左侧实色竖条 + 浅底；与播放跟随高亮 `.active`（渐变底）区分，
  叠加时渐变打底、竖条在前。
- 统计行下方常驻「⌨ 快捷键」提示条，键帽用 `<kbd>` 芯片样式（REQ-003 截图复核同款视觉语言）。

### 2.4 顺带修复（id 撞车）

详情页与工作台可能同时持有修订区 DOM（隐藏 tab 不清空 innerHTML），`getElementById`
会命中隐藏的那个。新增 `revVis(id)` 取「可见的」元素，应用于播放器/列表查找与
保存决策收集（只收集可见列表，防串数据）。键盘门控 E2E 正是靠此项拦住了
「面板切走后快捷键仍生效」的漏洞。
