## 0. 背景

徽章（👤N）原为行尾追加的最后一个子元素。切分行是固定 5 轨 grid
（序号/时间/徽章/文本/尾部 auto），整段行还带改判下拉、重新切分按钮——
徽章把子元素挤过第 5 轨后**折到第二行**，列表看起来很乱。

用户要求：人员ID 信息与其他信息**同一行**，位置放在**序号之后、时间戳之前**。

## 1. 核心需求

| ID | 需求 |
|---|---|
| REQ-1.1 | 👤 徽章渲染在 序号 与 时间戳 之间，与其余行内信息同行不折行 |
| REQ-1.2 | 未关联人员ID 的任务布局与从前完全一致（徽章轨塌缩为 0） |
| REQ-1.3 | 服务端渲染（重进任务/刷新）与 JS 关联后的插入位置一致 |
| REQ-1.4 | 移动端（≤900px）同样同行；时间戳照旧隐藏 |

## 2. 设计要点

- 行 grid 改 7 轨 `44px auto 190px 92px 1fr auto auto`，各已知子元素**显式 `grid-column`**：
  序号=1，人员徽章=2（auto 轨，无内容塌缩 0），时间=3，保留/删除徽章=4，
  文本=5，改判下拉=6，重新切分=7。显式列位使「徽章有无」不影响其他列对齐。
- `justify-self: start`（原来 end 是行尾语义，改为紧跟序号）。
- 移动端媒体查询同步为 7 轨模板；删除旧「徽章整行折下」规则；
  `.slirn-cut-abadge`（改判下拉）保留窄屏整行规则并补特异性（`.slirn-cut-row` 前缀）。
