# REQ-20260916-013 — 切分修剪行级连续播放 + 播放高亮 + 快捷键与修订阶段一致

## 需求原话

> 在切分修剪阶段，也需要使用快捷键对原始的字幕进行切分、删除等操作，当用鼠标点击某一条字幕记录时，进行连续播放，播放完一条之后继续播放下一条。在这个过程中，需要让字幕正在播放的这行高亮显示，同时可以用快捷键进行上下切换，同时也可以对选中的这条进行删除或者改为切分修剪状态，对于快捷键来说，切分修剪阶段应该和字幕修订阶段的开快捷键保持一致的功能

## 诊断

三个问题：

1. **段尾自停与连续播放矛盾**（REQ-20260916-011 M2 的设计）：行点击/↑↓ 预播 = 播到该段尾自动停，不符合"播完一条接下一条"的工作流。
2. **播放高亮一直不可见**：JS 在 timeupdate 里摆的是 `playing` 类，但 CSS 高亮样式全部写在 `.slirn-cut-row.active` 上（字幕/修订阶段同款用的是 `active`）——**home.css 里根本没有任何 `.playing` 规则**，DOM 断言能过（类在）但视觉上永远不亮。
3. **改判交互残留**：S 改判切分 → 展开行内编辑区 → 再按 S 取消改判，编辑区不关闭（取消分支不收起）。

## 修复（ec862ff）

| 改动 | 说明 |
|---|---|
| **行级连续播放** | 行点击 / ↑↓ / R / 空格（从未播放时）= 从该行起点播起，**移除 cutStopAt 段尾自动停机制**（变量整体删除）——视频自然推进到下一行、下下一行，直到用户空格暂停或视频结束 |
| **active 高亮修复** | timeupdate 摆 `active` 类（对齐字幕/修订阶段），既有 `.slirn-cut-row.active` 渐变样式点亮；段间缝隙（删除洞/被剔除字幕）保持前一行亮 |
| **改判收起编辑区** | `cutApplyDecision` 任何动作（K/D/S 含取消）先 `cutCloseResplit()`；改判 split 再重开——取消后不再残留 |
| Esc 语义明确 | Esc 只关编辑区，**切分决策保留**（徽章仍在）；再按 S 取消决策（此时编辑区一并收起） |
| 提示文案 | 面板 hint 更新为连续播放 + 快捷键说明 |

快捷键映射（与修订阶段同键位、共用自定义 keymap）：↑↓ 切换（跳行起点连续播放）· 空格 播/停 · R 重播本行 · **K/D/S 对选中行所属的整条字幕改判**（保留/删除/切分，作用于"原始字幕"=组级决策，再按同键取消）· Esc 关编辑区。子段徽章翻转（L1）与组头 ▶ 成片试听（REQ-20260916-012）不变。
