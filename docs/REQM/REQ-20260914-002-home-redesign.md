## 0. 背景

当前自定义首页沿用 Gradio 默认 `Soft` 主题 + 系统字体，外观与上游 funclip 首页几乎一致，缺乏差异化。

**目标**：重新设计为**玻璃拟态 (Glassmorphism) + Dashboard 仪表盘**风格，提升专业工具感与品牌识别度。

**用户决策**（已确认）：
- 视觉风格：玻璃拟态
- 布局：Dashboard 仪表盘
- 主题：亮 + 暗双主题可切换

---

## 4. 风险

| 风险 | 缓解 |
|---|---|
| `backdrop-filter` 在某些浏览器不支持 | 加 `-webkit-backdrop-filter` 前缀 |
| Gradio 自带 CSS 与自定义 CSS 冲突 | 用 `!important` 或更高 specificity 选择器 |
| 渐变背景与 Gradio 组件对比度差 | 关键文字用实色（白/深灰）+ backdrop-filter 加深 |
