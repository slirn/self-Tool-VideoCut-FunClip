## 0. 背景

字幕优化阶段每条修订建议行的最右侧有一个「替换为」输入框（截图红框标出），让用户填入替换文本后点 ✓ 确认。当前宽度明显偏窄，导致用户输入的长文案只能看到前几个字（截图中仅能看到"去做做处理的索"），影响填写体验与可读性。

## 1. 核心需求

| ID | 需求 |
|---|---|
| REQ-1.1 | 「替换为」输入框放宽到行最右边，与该行其他元素（行号 / 时间戳 / 原文本）共同分配横向空间，让用户能看到完整文字 |
| REQ-1.2 | 输入框宽度的调整不应破坏现有 grid 布局（行号、时间戳、原文本、✓ 按钮的相对位置不变） |
| REQ-1.3 | 响应式：在窄屏（≤900px 等）下也不应被裁到不可用 |

## 2. 验收标准

- [ ] AC-1 输入框在常规桌面宽度（≥1200px）下宽度足以展示整行常见替换文本（如 30+ 字符）不截断
- [ ] AC-2 行的 grid 结构不变，行号/时间戳/原文本位置与之前一致
- [ ] AC-3 ✓ 确认按钮仍在行最右，且不被挤压变形
- [ ] AC-4 窄屏下仍可输入（不要求与桌面同宽度，但不出现不可点/不可见）
- [ ] AC-5 不影响"确认替换并保存 / 下载优化字幕 SRT / 重新优化"等其它功能

## 4. 技术方案

**改 grid 模板列** —— 行模板从 3 列升 4 列 `44px 92px 1fr 260px`：
- 列 1 行号 44px、列 2 时间戳 92px、列 3 正文 1fr（弹性）、**列 4 替换栏 260px（恒宽）**
- `_line_html` 把每个 occ chip 同时渲染到正文流（保留删除线上下文）+ 替换栏（可编辑的输入框）
- `.slirn-opt-col` 右对齐 flex column，多处 occ 竖直 stack
- `input.slirn-opt-after` 改为 `flex: 1 1 auto; min-width: 0`，自适应填满替换栏
- 无 occ 的行（`:not(.has-occ)`）替换栏 `display: none`，不占位
- ≤720px：替换栏 grid-column 跨全列到正文下方、occ chip wrap

**理由**：原 3 列 grid 把 `<input>` 塞在 `1fr` 正文列里，被长正文挤到 `max-width: 14em` ≈ 175px，所以才截字。提升为独立列后恒宽。

**接受的口径**：occ chip 在正文流 + 替换栏各渲染一次 —— 删除线原文 → → 出现在行中（上下文定位）+ 替换栏（可编辑入口）。视觉重复可接受；如需只保留替换栏、删正文流里的 chip，可后续优化。
