# REQ-20260930-094 - 短视频多素材混剪工作台

- **日期**：2026-09-30
- **类型**：新功能
- **状态**：已实现，自动验证通过
- **风险初判**：一般偏高。涉及多素材、外部 LLM、媒体渲染、异步任务和前端工作台；
  不涉及数据删除、权限放宽或不可回滚迁移。

## 1. 目标

在当前 Video Studio 中新增独立的短视频混剪模块。用户可以从长视频任务产物和
自行上传的视频、图片、音频中创建短视频项目，使用外部 LLM 生成多版本分镜，
人工调整视频片段、转场、B-roll、标题、Hook、字幕和 BGM，并导出 9:16 成片。

## 2. 首个可验收切片

给定一个已有任务和一个短视频项目：

1. 自动导入任务现有成片为视频素材。
2. 用户可上传至少一个额外视频/图片/音频作为 B-roll 或 BGM。
3. 输入创作 Brief 后，可用当前 LLM 生成 3 个分镜版本；LLM 不可用时使用本地规则兜底。
4. 每个版本包含标题、Hook、字幕、视频片段、转场、B-roll 和 BGM 设置。
5. 用户可在页面上调整基础字段并渲染。
6. 输出为 1080x1920、H.264/AAC 的 MP4。

## 3. 边界

本期包含：

- 任务内短视频项目创建、列表、打开和删除。
- 视频、图片、音频素材上传。
- LLM 分镜生成与本地规则降级。
- 视频片段、B-roll、标题、Hook、字幕、BGM 的结构化编辑。
- fade/wipe/slide 基础转场。
- 异步渲染、状态查询、取消和产物下载。

本期不包含：

- 抖音、视频号等平台自动发布。
- 人脸追踪、主体跟踪和动态运镜。
- 音乐节拍点自动卡点。
- 跨任务或跨用户公共素材库。
- 专业级逐帧时间线、拖拽轨道和复杂特效。

## 4. 已确认决策

- 产品类型：多素材混剪、转场、B-roll、带货素材型短视频。
- 默认画布：9:16，1080x1920。
- 默认时长：30-60 秒。
- 默认版本数：3。
- 文本内容：标题、Hook、字幕、BGM。
- 字幕和素材元数据允许发送给已配置的外部 LLM。
- 短视频模块与长视频六阶段流水线逻辑分离，只复用认证、LLM、任务素材、
  异步任务、执行历史和产物浏览基础能力。

## 6. 风险

- FFmpeg 多输入滤镜图错误会直接导致渲染失败，需保留完整 stderr 诊断。
- 外部 LLM 输出结构可能漂移，必须做字段白名单和本地规范化。
- 素材来源可能分辨率、方向、音轨不一致，渲染器需要统一转为竖屏画布。
- 长视频项目中的用户数据仍受任务权限约束，短视频接口不得绕过任务访问控制。
