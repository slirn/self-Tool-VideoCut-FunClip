## 0. 背景

任务列表卡片目前只有「详情 / 删除」。用户要求：
1. 每个任务卡加 **编辑** 与 **剪辑** 两个按钮；
2. 编辑进入此前完成的「新建任务」页（同一套页面，预填该任务信息）；
3. 剪辑进入 **剪辑工作台**：上方任务相关信息，左侧任务各阶段，右侧每阶段执行情况。

### 过程中发现并修复的缺陷

**编辑页丢失「不在公共库」的 pick 词**（浏览器实测暴露）：任务 pick 词「训练营」被从公共热词库删除后，编辑页 picker 无对应 cell → 词不可见，且保存时 `collectPickedHotwords()` 只读 picker cell → **词被永久丢弃**（数据丢失）。修复：`_render_create_task` 预填时，pick 词若不在公共库，追加「任务已选（不在公共库）」分区并预选中，保存时可正常带回。回归：单测 + E2E + 浏览器三处均断言该分区存在且 chips=3。
