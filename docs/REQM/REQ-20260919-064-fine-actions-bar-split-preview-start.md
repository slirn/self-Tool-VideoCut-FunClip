# REQ-20260919-064 精剪视频·操作栏拆分 + 预览开始时间

## 背景

用户反馈精剪视频·操作栏（两个红框区域）需要调整：

1. **拆分操作栏为两行**：当前"AI智能布局 + 生成预览 + 预览时长 + 导出最终视频"和"模板名 + 保存设置参数 + 引用参数 + 状态"在同一行（`.slirn-fine-actions-bar` flex 横向），元素挤在一起。拆成上下两行后视觉更清爽，也更容易点击。

2. **加「预览开始时间」**：用户希望能在不同时间点预览精剪视频，检查不同片段的合成效果（例如跳到视频 30 秒看后半段）。当前只能从 0 开始。

## 验收标准

| ID | 验收项 |
|---|---|
| AC-1 | 操作栏拆成上下两行：上 = AI智能布局 + 生成预览 + 预览开始时间 + 预览时长 + 导出最终视频；下 = 模板名 + 保存设置参数 + 引用参数 + 状态 |
| AC-2 | 「预览开始时间」是 number input，单位秒，默认 0，min=0，step=1 |
| AC-3 | 后端接受 `preview_start` 字段，传给 ffmpeg 作为 `-ss`（替换原 `-ss 0`） |
| AC-4 | preview_start + preview_duration ≤ 源视频时长，否则后端钳到合理范围（不返回错误，start 自动后移） |
| AC-5 | 封面（片头）仍正常播放在新开始时间前 2 秒（即视频流从 start_time 开始截取，封面相对位置不变） |
| AC-6 | E2E：start=0 → 与现在一样；start=5 → 视频流从 5 秒开始 |
| AC-7 | 单元测试：`_render_fine_cut_zone` 输出包含 `slirn-fine-preview-start` input；后端 endpoint 接受 `preview_start` 字段 |

## 不做的事

- ❌ 不动预览时长（仍是 2-30 秒）
- ❌ 不动保存/引用模板的逻辑
- ❌ 不持久化 preview_start 到 fine_compose（仅作每次渲染的临时参数）
- ❌ 不把 start_time 加进全局参数模板
- ❌ 不改 cover 渲染逻辑（cover 仍固定 2 秒在视频流前面）
