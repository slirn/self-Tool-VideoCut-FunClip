# REQ-20260916-015 — 试听与连续播放只播保留内容（成片效果）

## 需求原话

> 在切分修剪阶段，每一个切分修剪的字幕点击其右边的试听时之播放保留部分的内容，而不去播放删除部分内容，这个试听的效果就是在切分处理之后是个什么样的效果。包括在点击某一行字幕时，整体播放时也不要播放删除部分的字幕内容

## 诊断

两处播放口径与「执行口径」不一致（执行口径见 `cutlist_service.effective_keep_units`：组级改判 delete → 整条剔除；split 子段按 mark；组改判 keep → 整段保留、子段作废）：

1. **组头 ▶ 试听**（REQ-20260916-012）：只过滤子段 `data-mark`，完全不看组级 `data-act`——已改判删除的组照播（成片里根本没有）；已改判保留的组仍按子段跳播（执行时是整段保留，不该有跳变）。
2. **行级连续播放**（REQ-20260916-013）：点行后自然连续播放——删除洞（mark=delete 子段）与改判删除的整条字幕内容**照播**，听到的不是成片效果。

## 实现（9d4d547）

| 改动 | 说明 |
|---|---|
| `cutRowKept(row)` | 前端镜像执行口径：组级 `data-act=delete` → 整条剔除；切分组子段按 `data-mark`（组改判 keep → 子段作废、整段保留）；整段组默认保留 |
| `cutKeepAllFrom(row)` | 从点击行到列表末尾的全部保留区间（时间序）——行级连续播放的跳播序列 |
| `cutPreview`（行点击/↑↓/R/空格） | 从点击行起**跳播保留区间**：播完一段 seek 下一段，删除洞与改判删除整条直接跳过（= 成片效果）；点击的行本身是删除内容 → 从其后下一个保留区间播起；行级模式不显示试听条 |
| `cutPlayGroupKeep`（组头 ▶） | 改判删除 → toast「本组已改判删除 — 成片中没有这段内容」不开播；改判保留 → 整段一段（首行起点到末行终点，无子段跳变）；其余按 keep 子段跳播 + 成片口径试听条（REQ-20260916-012 语义不变） |
| `cutKeepMode` | 区分跳播来源：`'group'`（显示试听条、空格暂停即退出）与 `'row'`（无试听条、**空格暂停保留序列**，恢复后继续跳过删除内容）；播放完毕/重渲染两者都清 |
| kbsel 语义修正 | **点哪行选中停在哪行**（播放起点可能是其后的保留区间）——键盘 K/D/S 改判目标可预期，不被播放跟随带偏；跳播时选中仍跟随播放行 |

边界说明：跳播序列在点击时构建，播放途中改判不实时重建（下次点行/试听重建）；用户回拖到点击行之前则自然播放（自由听原声），再进入保留区间后跳播恢复。
