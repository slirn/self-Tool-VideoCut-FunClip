# REQ-20260917-024 — 字幕修订状态跳转（上一条/下一条）

## 需求原话

> 在字幕修订阶段再添加一个功能，这个功能主要是选定某个建议状态或者决策状态，然后选上一个下一个来在整个字幕列表中跳转到指定的这个状态的下一条记录或者上一条记录，这样可以方便用户跳转到这个记录之后还能看到上下文之间的语句，连贯没错，决定如何处理这条记录

## 设计

筛选条（建议状态/决策状态维度 + 状态 chips）末尾新增 **⬆ 上一条 / 下一条 ⬇**
两个按钮，按**当前选中的状态**在整个字幕列表中跳转：

| 行为 | 说明 |
|---|---|
| 显示全部行 | 跳转 = 完整列表（与「筛选藏行」互补）——目标行上下文语句可见，便于结合前后文决定处理 |
| 匹配口径 | 与筛选项**完全同源**（`revFilterMatch`：建议维度=模型判定；决策维度=实质类别，含「采纳建议」） |
| 定位 | 目标行 `kbsel` 高亮 + `scrollIntoView(center, smooth)` 居中；播放器已加载则定位到行起点（与 ↑↓ 键同源，不强制播放） |
| 循环 | 到末条/首条后继续点击循环跳转（toast 提示「已到最后一条，继续将循环」） |
| 计数 | 状态栏显示 `跳转「删除」3/5 · 显示全部 1581 条（上下文可见）` |
| 锚点 | 上次跳转行 → 键盘选中行 → 首条；切换筛选维度/筛选项时重置 |
| 选「全部」 | 退化为整表上一/下一条（与 ↑↓ 等效，按钮始终可用） |
| 无匹配 | toast「没有『XX』状态的行」+ 计数栏明示 |

实现：行级 `data-sugg/data-decision/data-final` 属性（REQ-20260916-010 已有）
直接复用，纯前端（+48 行 JS + 10 行 CSS + 4 行 HTML），无新端点、无新依赖。
