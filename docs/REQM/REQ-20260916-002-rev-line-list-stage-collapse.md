## 1. 需求（用户原话转述）

> 把字幕修订阶段右边的列表展现形式，改成跟字幕生成列表展现形式一样。
> 方便看每一行的信息以及按顺序播放时对照字幕。
> 同时修改左边的阶段列表可以向左边折叠，这样可以增加右边的宽度，
> 加一个展开左边阶段列表的按钮，使其能够恢复回来。

两个诉求：
1. **修订列表行式化**：从「卡片堆叠」改为与字幕生成列表一致的「每条一行」，
   按顺序播放时逐行对照字幕 + 逐行决策。
2. **阶段列表折叠**：左侧 8 阶段列表可收起 → 右侧工作区变宽；提供展开按钮恢复。

## 2. 设计

### 2.1 修订行式列表（对齐字幕生成列表）

- 每条建议一行，grid `44px 216px 1fr 150px 26px` 五列：
  **序号 | 时间段 | 类别徽章+字幕文本 | 决策下拉 | ▾/▴ 展开钮**。
  序号/时间两列宽度与字幕生成列表（`44px 216px 1fr`）一致 → 两列表格线纵向对齐。
- 徽章内联进文本列开头（切分修剪/保留/删除/人工复核四类等宽短标签），
  不单独占列，保证文本列可用宽度。
- **决策下拉留主行**（150px 列）：按顺序播放时逐行决策不必展开详情。
- 详情块 `.slirn-rev-detail` 默认收起（`display:none`），收进三样内容：
  🤖 模型分析 note、✂ 建议保留 keep_text、手动处理说明 input。
- **自动展开规则**：`category=="review"` 或已有 `user_note` 的行初始即 open
  （20/389 条自动展开），其余点 ▾ 手动展开/▴ 收起。
- 点击行（主行非交互区）仍定位播放；排除区扩为 `select, input, button, a, .slirn-rev-detail`。
- save-revision 收集逻辑不变（querySelector 与嵌套位置无关）；save_revision API 不变。
- 窄屏（<720px）：4 列（隐藏时间列），详情缩进减小。

### 2.2 阶段列表折叠

- 开关两处：阶段卡头部 **「« 收起」**（slirn-btn-mini）+ 顶部按钮行
  **「🧭 展开阶段」**（`.slirn-wb-stages-expand`，CSS 默认 `display:none`，
  仅收起后显示 → 不与顶栏常驻按钮抢位）。
- 实现：`#slirn-tab-workbench-inner` 上切 class `wb-stages-collapsed`；
  CSS `.wb-stages-collapsed .slirn-wb-stages{display:none}` +
  `.wb-stages-collapsed .slirn-wb-main{grid-template-columns:1fr}`（右侧占满）。
- **状态记忆**：localStorage `slirnWbStagesCollapsed`（'1'/'0'，try/catch 包裹）；
  `applyWbStagesState()` 在 `openWorkbench` 的 innerHTML 替换后调用 →
  保存决策/轮询完成触发的重渲染不丢折叠状态。
- 实测收起后右侧工作区 942px → 1216px（+274px）。
