# REQ-20261015-124 — Stage 3 系统默认提示词补充：独立性 / 逐条时长 / 开头引子 / 结尾收束

> 状态：✅ 已完成（2026-10-15）
> 关联：[REQ-20261015-121](REQ-20261015-121-sv-stage3-prompt-params-and-params-row.md)
> （提示词参数化基建；本次为纯文案追加，无新增占位符）

## 1. 需求（用户原话要点）

1. 系统默认提示词要明确说明：最终生成的多个片段短视频**相互之间不存在
   任何前后关系或依赖关系**，每个短视频说的是自己的一件事；
2. 因此**时长不要按平均计算**是否满足上下限，要**单独判断每一个**片段；
3. 每个片段**开头要有合适的引子**引入（第一句不能莫名其妙）；
4. **结尾要能关闭话题**。

## 2. 实现（`short_video_service.py::_STAGE3_SYSTEM_PROMPT_TMPL`）

| 位置 | 改动 |
|---|---|
| 新增块「多条短视频相互独立（硬性要求）」 | ① 相互无前后/依赖关系、每条独立一件事、不允许承接引用；② 所有标准逐条独立判断、禁止用平均时长代替、「平均达标」无效 |
| 切片筛选标准 #2 | 独立完整 →「不看完整课程、也不依赖其他条短视频」 |
| 切片筛选标准 #3 | 追加「时长必须逐条单独判断，不允许用各条平均时长代替」 |
| 切片筛选标准 #4 | 「钩子强」→「开头有引子」：钩子 + 自然引入话题，禁止第一句莫名其妙/悬空 |
| 切片筛选标准 #7（新增） | 「结尾关闭话题」：最后一句必须收束/关闭话题（结论/总结/点题/号召），不允许戛然而止 |
| 自检 1) | 「逐条把…标注相加（禁止用各条平均时长代替）」 |
| 自检 2) | 核对清单同步为 开头引子/结尾关闭话题，并注明逐条独立判断 |
| 自检 3) | 第一句=自然引子而非莫名其妙；最后一句=收束并关闭话题 |

JS `_stage3RenderSystemPrompt` 与 UI `data-prompt`/`data-prompt-tmpl` 只做
占位符替换/整串引用，新文案自动生效，零 JS/UI 改动。解析端核查代码本就
逐条判断（`hl_lines_duration_sec` per highlight），与提示词口径一致。
