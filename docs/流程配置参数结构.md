# 流程配置参数结构说明（保存后的完整数据结构）

> **版本**：v1.0（2026-09-30，对应 REQ-20260930-092）
> **适用**：流程配置面板（红框①–⑥全部区段 + 运行模式/停止阶段）保存后的落盘结构
> **代码依据**：`slirn_home/pipeline_service.py`（权威 schema）、`slirn_home/flow_profiles.py`、`slirn_home/static/pipeline.js`

---

## 1. 总览：参数存在两个地方

| 存储 | 文件位置 | 写入时机 | 用途 |
|---|---|---|---|
| **任务级配置** | `slirn-standalone/tasks/<任务ID>/outputs/pipeline.json` | 面板任何改动 800ms 自动保存；点「💾 保存配置」立即保存；套用模板即保存 | 本任务流水线怎么跑 |
| **全局模板库** | `slirn-standalone/tasks/_global_flow_profiles.json` | 下拉选「💾 将当前配置存为模板…」命名保存 | 跨任务复用（任何任务的下拉可套用） |

**关键关系**：两处的 `config` 字段**完全同构** —— 模板存的就是一份规范化的任务配置。套用模板 = 把模板的 `config` 写进任务的 `pipeline.json`。

---

## 2. 任务级 pipeline.json 完整结构

文件：`tasks/<任务ID>/outputs/pipeline.json`（原子写：先 `.tmp` 再替换）

```json
{
  "version": 4,
  "config": {
    "subtitle_generation": {
      "speaker_diarization": true
    },
    "subtitle_review": {
      "accept_all_suggestions": true,
      "skip_categories": [],
      "rigor": "medium",
      "link_person_ids": true
    },
    "rough_cut": {
      "delete_speakers": [],
      "default_decision": "keep",
      "link_person_ids": true
    },
    "rough_compose": {},
    "optimize": {
      "accept_all_replacements": true
    },
    "fine_cut": {
      "enabled": true,
      "params_source": "current",
      "range_enabled": true,
      "preview_start": 0.0,
      "duration": 600.0
    },
    "run_mode": "stop_after",
    "stop_after": "subtitle_review"
  },
  "updated_at": "2026-09-30T14:01:55",
  "history": [
    {
      "started_at": 1760000000.0,
      "finished_at": 1760000900.0,
      "duration_ms": 900000,
      "status": "stopped",
      "stages_done": ["subtitle_generation", "subtitle_review"],
      "stages_skipped": [],
      "since": null,
      "error": null
    }
  ]
}
```

### 顶层字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `version` | int | 固定 `4`（v5 schema 的标记值，历史遗留编号） |
| `config` | object | **核心：面板全部参数**（见 §3 逐字段表） |
| `updated_at` | string | 最后保存时间 `YYYY-MM-DDTHH:MM:SS`（自动保存也更新此值） |
| `history` | array | 最近 **10 条**流水线运行记录（超出丢最旧） |

### history 单条结构（每次「▶ 从头跑 / ▶ 续跑」结束追加）

| 字段 | 类型 | 说明 |
|---|---|---|
| `started_at` / `finished_at` | float | Unix 时间戳（秒） |
| `duration_ms` | int | 总耗时毫秒 |
| `status` | string | `done`（全部跑完）/ `stopped`（按配置停在指定阶段）/ `error` |
| `stages_done` | string[] | 真正跑通的阶段 key 列表 |
| `stages_skipped` | string[] | 因配置关闭而跳过的阶段（⚠️ 黄徽章那类） |
| `since` | string\|null | 续跑时的起始阶段（从头跑为 null） |
| `error` | string\|null | 失败原因（成功为 null） |

## 3. config 逐字段表（面板控件 ↔ 字段对照）

### 顶层运行控制（头部控制区）

| 字段 | 类型 | 默认 | 面板控件 | 取值与含义 |
|---|---|---|---|---|
| `run_mode` | string | `"stop_after"` | 「运行模式」下拉 | `"stop_after"` 按停点停 / `"to_end"` 一键跑到底 |
| `stop_after` | string\|null | `"subtitle_review"` | 「完成到哪个阶段停」下拉 | 六阶段 key 之一；**`run_mode="to_end"` 时强制为 `null`**（规范化保证） |

### ① 字幕生成 subtitle_generation

| 字段 | 类型 | 默认 | 面板控件 | 含义 |
|---|---|---|---|---|
| `speaker_diarization` | bool | `true` | ☑ 区分说话人 | 识别说话人编号（多人视频用） |

### ② 字幕修订 subtitle_review

| 字段 | 类型 | 默认 | 面板控件 | 含义 |
|---|---|---|---|---|
| `accept_all_suggestions` | bool | `true` | ☑ 默认接受所有建议 | 不勾 → 全部留 pending 人工审 |
| `skip_categories` | string[] | `[]` | 「跳过建议类别」文本框 | 逗号分隔；命中类别的建议留 pending。类别名 = 大模型建议的 `category` 值（如口误、重复等，LLM 产出） |
| `rigor` | string | `"medium"` | 严谨性四选一卡片 | `high` 严格打磨 / `medium` 意思正确即可 / `low` 只去严重问题 / `custom` 自定义（流水线通道 custom 自动降级 medium） |
| `link_person_ids` | bool | `true` | ☑ 自动关联人员ID | 识别出的人员编号自动挂到任务成员 |

### ③ 切分修剪 rough_cut

| 字段 | 类型 | 默认 | 面板控件 | 含义 |
|---|---|---|---|---|
| `delete_speakers` | string[] | `[]` | 「删除某些说话人」文本框 | 逗号分隔说话人编号，整段剔除其全部记录 |
| `default_decision` | string | `"keep"` | 「默认决策」下拉 | 修订阶段未明确决策的段落：`keep` 保留 / `delete` 删除 |
| `link_person_ids` | bool | `true` | ☑ 自动关联人员ID | 同上 |

### ④ 粗剪合成 rough_compose

无参数（`{}`），必做阶段。

### ⑤ 优化字幕 optimize

| 字段 | 类型 | 默认 | 面板控件 | 含义 |
|---|---|---|---|---|
| `accept_all_replacements` | bool | `true` | ☑ 默认接受所有替换 | 不明确字词替换全部自动接受 |

### ⑥ 精剪合成 fine_cut

| 字段 | 类型 | 默认 | 面板控件 | 含义 |
|---|---|---|---|---|
| `enabled` | bool | `true` | （无复选框） | radio 语义下恒 `true`；**想跳过精剪 → 顶层 `stop_after` 停在 `optimize`**，不要写 `false`（规范化会把 `range_enabled=true` + `enabled=false` 迁移回 `true`） |
| `params_source` | string | `"current"` | 「设置参数」下拉 | `"current"` 用本任务精剪页保存的参数；`"template:<模板ID>"` 用精剪全局模板（`p_` 开头 id） |
| `range_enabled` | bool | `true` | 导出方式单选卡片 | `true` =「✂️ 按区间导出一段」/ `false` =「🎬 出整个片」 |
| `preview_start` | float | `0.0` | 「导出起点」 | 秒（界面输 HH:MM:SS，存秒数） |
| `duration` | float | `600.0` | 「时长」 | 秒（默认 10 分钟；「出整个片」时此项忽略） |

> 封面图 / 背景图 / 背景音乐**不在** pipeline.json —— 实际素材路径在 `fc.json`（fine_compose）的 `materials.{cover,bg,audio}.path`，由工作台第 6 阶段详情页上传维护。

## 4. 保存时的规范化规则（validate_config）

任何保存（自动 / 手动 / 模板）都过同一套规范化，**坏值兜底不抛异常**：

1. **缺字段补默认**；用户显式保存的值（含 `false`）原样保留，不被新默认覆盖；
2. 阶段内的旧 `stop_after` 字段**丢弃**（顶层 `stop_after` 是唯一权威）；
3. `run_mode="to_end"` → `stop_after` 强制 `null`；
4. 旧数据（v4）无 `run_mode` → 按 `stop_after` 是否为 `null` 推算；
5. `rigor` 脏值 → 回落 `medium`；
6. `fine_cut.enabled` / `range_enabled` 非 bool → 回退 `true`；`range_enabled=true` → `enabled` 强制 `true`（legacy 迁移）；
7. `link_person_ids` 非 bool → 回退 `true`。

## 5. 全局模板库 _global_flow_profiles.json

文件：`tasks/_global_flow_profiles.json`（原子写；损坏自动回退空库 `{"_schema":1,"profiles":[],"updated_at":""}`，不崩）

```json
{
  "_schema": 1,
  "profiles": [
    {
      "id": "fp_20260930_140139_6d9bde",
      "name": "课程全自动",
      "saved_at": "2026-09-30T14:01:39",
      "task_id_origin": "20260924-001",
      "config": { "...与 §3 的 config 完全同构..." : "" }
    }
  ],
  "updated_at": "2026-09-30T14:01:55"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | `fp_<时间戳>_<随机hex>`，全局唯一，前端下拉 value 用 `fp:<id>` |
| `name` | string | 模板名（≤30 字；重名自动加 `(2)`/`(3)`；空名兜底「未命名」） |
| `saved_at` | string | 保存时间；列表按此倒序 |
| `task_id_origin` | string | 从哪个任务存出来的（溯源用，套用时不读它） |
| `config` | object | 规范化后的完整 config（同 §3） |

---

## 6. 面板上的模板下拉 value 约定

| value | 含义 |
|---|---|
| `default_tpl` / `semi` / `full` | 三套内置模板（人工全审 / 半自动 / 全自动） |
| `fp:<模板ID>` | 用户保存的模板（选中时显示 🗑 删除按钮） |
| `fp:_save_as` | 固定项「💾 将当前配置存为模板…」（触发命名保存） |
| `custom` | 当前配置不匹配任何模板（手改任何控件后自动回到此项） |

---

## 7. 快速对照：改了面板上的东西 → 哪个文件变

| 操作 | 落盘 |
|---|---|
| 勾/取消勾选任何复选框、切单选卡片、改下拉、输文本 | 800ms 后写本任务 `pipeline.json`（`config` + `updated_at`） |
| 点「💾 保存配置」 | 立即写本任务 `pipeline.json` |
| 套用内置/用户模板 | 模板 config 写进本任务 `pipeline.json`，下拉保持选中该模板 |
| 下拉选「💾 存为模板…」并命名 | 追加一条到 `_global_flow_profiles.json`（**不动**本任务） |
| 🗑 删除模板 | 从 `_global_flow_profiles.json` 移除（已保存过的任务不受影响） |
| 跑一次流水线 | 本任务 `pipeline.json` 的 `history` 追加一条（最多 10 条） |
